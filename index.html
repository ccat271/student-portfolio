  • 기간 2025.03 – 2025.06
  • 역할 데이터 전처리 · 모델링
  • 핵심 지표 F1 0.81
분류 (Classification)

통신사 고객 이탈 예측 모델

문제 정의

구독형 서비스에서 이탈 고객을 사전에 식별하지 못하면 유지 비용이 급격히 늘어납니다. 이탈 고객 비율이 전체의 약 7%에 불과한 불균형 데이터에서, 이탈 가능성이 높은 고객을 놓치지 않고 찾아내는 것이 목표였습니다.

접근 방법

  • 결측치와 이상치를 정리하고, 계약 기간·요금제·이용량 지표를 파생 변수로 생성
  • 클래스 불균형을 해결하기 위해 SMOTE 오버샘플링과 클래스 가중치를 비교 실험
  • 로지스틱 회귀 · 랜덤 포레스트 · LightGBM을 교차검증으로 비교하고 LightGBM을 최종 선택
  • SHAP 값으로 이탈에 영향을 주는 상위 변수를 해석하고 결과를 보고서로 정리

결과

0.81F1 점수
0.87ROC-AUC
-21%오탐 감소

배운 점

정확도만 보면 불균형 데이터의 함정에 빠진다는 것을 확인했고, 지표 선택과 임계값 조정이 실제 활용도에 얼마나 큰 영향을 주는지 배웠습니다.

  • 기간 2025.03 – 2025.06
  • 역할 특성 설계 · 회귀 모델링
  • 핵심 지표 RMSE -18%
회귀 (Regression)

건물 에너지 사용량 예측 모델

문제 정의

에너지 비용을 줄이려면 어느 건물이 얼마나 쓸지 미리 알아야 합니다. 건물 면적, 사용 연수, 단열 등급, 월평균 기온을 입력으로 월별 에너지 사용량을 예측하는 회귀 모델을 설계했습니다.

접근 방법

  • 연속형 변수의 분포를 확인해 로그 변환과 표준화를 적용
  • 기온 · 면적 상호작용 항과 계절 더미 변수를 추가해 특성 확장
  • 릿지 회귀 · 그래디언트 부스팅 · XGBoost를 비교하고 XGBoost를 최종 선택
  • 잔차 분석으로 과소 예측 구간을 찾아 모델을 재보정

결과

-18%RMSE 개선
0.91결정계수 R²
3.4%평균 오차율

배운 점

모델 성능의 절반은 특성 설계에서 나온다는 것을 체감했습니다. 특히 기온과 면적의 상호작용 항이 예측력을 크게 끌어올렸습니다.

시간대별 전력 수요 예측 모델

과거 전력 사용 패턴과 요일·계절 요인을 반영해 24시간 뒤 전력 수요를 예측했습니다.

  • 기간 2025.07 – 2025.09
  • 역할 시계열 분석 · 앙상블
  • 핵심 지표 MAPE 4.2%
시계열 예측 (Time Series)

시간대별 전력 수요 예측 모델

문제 정의

전력 수요는 시간대·요일·계절에 따라 크게 달라지며, 예측을 틀리면 공급 비용이 바로 늘어납니다. 1시간 단위 과거 데이터를 이용해 다음 24시간 수요를 예측하는 모델을 만들었습니다.

접근 방법

  • 결측 구간을 보간하고 이상 사용량을 탐지해 정제
  • 요일·시간대·공휴일 더미와 24시간 · 168시간 지연 변수 생성
  • Prophet으로 추세와 계절성을 분해하고 LSTM으로 비선형 패턴을 학습
  • 두 모델의 예측값을 가중 평균으로 결합해 최종 앙상블 구성

결과

4.2%MAPE
24시간예측 지평
+9%단일 모델 대비

배운 점

시계열에서는 검증 구간을 어떻게 자르느냐가 성능 평가를 좌우한다는 점을 배웠고, 단일 모델보다 앙상블이 안정적이라는 것을 확인했습니다.
